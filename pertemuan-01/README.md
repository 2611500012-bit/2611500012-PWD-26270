# pertemuan-01
1. Konsep Dasar Pemrograman Web
   Pemrograman web adalah proses membuat aplikasi atau situs yang berjalan melalui browser. Terdiri dari tampilan dan interaksi, pengolahan data, dan server<br>

2. Arsitektur Klien-Peladen Client-Server
   client biasanya berupa browser yang meminta data atau layanan. server menerima permintaan, memprosesnya, lalu mengirimkan hasil kembali kepada client<br>

3. HTTP Request dan Response
   request adalah permintaan dari client ke server, misalnya GET atau POST. Response adalah jawaban server yang memiliki status, header, dan isi body, seperti HTML atau data JSON<br>

4. HTML, CSS, JavaScript, PHP, dan MySQL

   HTML → menyusun struktur halaman
   CSS → mengatur tampilan
   JavaScript → memberikan interaksi dan perilaku dinamis
   PHP → menjalankan logika di sisi server
   MySQL → menyimpan dan mengelola data<br>

5. Hubungan Antarteknologi
   Teknologi tersebut bekerja bersama: HTML + CSS + JavaScript membentuk sisi pengguna, PHP memproses permintaan di server, sedangkan MySQL menyediakan penyimpanan data<br>
